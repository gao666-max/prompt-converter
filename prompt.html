✦ 写提示词 · 五条铁律
  1. 1给上下文，别给空指令。好提示词 = 背景 + 目标 + 约束 + 验收标准。
  2. 2一次一个目标。别把 5 件事塞进一段语音，拆开说，一个诉求一条。
  3. 3验收标准写清楚。「做完」到底长什么样——能跑 / 能看 / 有数据，AI 才知道何时交差。
  4. 4先问「要解决什么问题」，再问「用什么技术」。别一上来就接 MySQL / 上 RAG。
  5. 5跨窗口用交接文档。背景 + 现状 + 下一步 + 踩坑，比口头转述可靠一百倍。
1 输入你的原始想法
按住 Alt 说话，松开自动识别（或点「语音输入」按钮）。
2 识别结果
3 缺的信息 · 补一下
✓ 四个要素都齐了，直接看输出
